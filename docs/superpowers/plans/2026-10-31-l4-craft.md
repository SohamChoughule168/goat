## Asset and dependency decisions

- No Rive or Spline asset exists in the repository. Station 09/10 ship the poster, the disabled run control and a visible **Asset pending** state. No fake runtime, no placeholder package.
- No `zdog`, `vanilla-tilt`, `@rive-app/react-canvas` or `@splinetool/react-spline` dependency is added. Stations 07 and 11 are hand-rolled with CSS/DOM; this is the smallest tool that works and keeps the route light.
- Station 08 gets a new hand-authored Lottie file at `public/craft/station-08.json`; the existing trust seal is not reused.
- Station 04 imports R3F only after activation via `next/dynamic` with `ssr: false`; the canvas uses `frameloop="demand"` and invalidates on control changes.
- Station 05 reuses `getScrollMotion()` and reverts its own `gsap.context()`. No page-level pin, so no scroll trap.
- Station 06 uses Canvas 2D with a projection function; no WebGL, no second R3F scene.
- Station 08 reuses the proven `lottie-web` activation pattern from `trust-seal.tsx`, including reduced-motion play-once and `data_failed` fallback.

## Layout

- Shared `EvidenceHeader` with a new `kicker` prop: `Workshop / CRAFT — 11 stations`.
- Intro band: how to read the page, live/pending legend, "craft proof, not client proof".
- Twelve-column bench grid: wide 12, half 6, third 4 at ≥1024px; two columns at ≥701px; single column below.
- Every station frame: index, skill, title, state badge, fixed-aspect stage, poster, explanation, runtime/payload/fallback metadata, controls, `aria-live` status.
- One dark plate (station 03) for rhythm. Everything else stays bone / ink / cobalt.
- No glass, glow, gradient text, cursor followers, particle fields or ambient loops.

## Motion

- CSS entrances use `--ease-out` (600ms) and state changes use `--ease-state` (180ms).
- Station 01/02/11 reveal sequences are CSS animations inside the activated panel; no timers to leak.
- Station 03 range input is direct manipulation; Play is a 900ms one-shot and is hidden under reduced motion.
- Station 05 scrub is bounded to the station frame; Reset kills the trigger and shows the finished static state.
- Station 07 only tilts on fine pointers; touch gets the flat card.
- Station 08 follows the trust-seal policy: poster by default, play once under reduced motion.
- Global reduced-motion rule already collapses CSS animation/transition durations; stations add explicit static states where JS would otherwise animate.

## Accessibility

- Every poster is decorative (`aria-hidden`, `focusable="false"`); the station title and explanation carry the meaning.
- Controls are native buttons/inputs with visible labels. No focus traps.
- Live regions announce run/reset/pending states. Pending stations expose a disabled run button with a described reason.
- Canvas surfaces are `aria-hidden`; the state is mirrored in visible text.
- Add `/craft` to `e2e/a11y.spec.ts` (22 routes).

## Performance budget

- Initial `/craft` JS: frame, content and DOM-only stations; no R3F, GSAP, Lottie or Three in the first load.
- Station 04: ~230KB gzip R3F/Three chunk, activation only.
- Station 08: ~75KB gzip Lottie runtime, activation only.
- Station 05: shared lazy motion chunk, activation only.
- LCP ≤2.5s mobile, CLS ≤0.05, INP ≤200ms, TBT ≤300ms; Lighthouse mobile ≥90, desktop ≥95, a11y 100.
- Every stage has a fixed `aspect-ratio`; posters and live panels occupy the same box, so activation cannot shift layout.
